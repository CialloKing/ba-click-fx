## 独立耗时采样

Windows，Edge 149.0.4022.69 无头模式，Node v24.16.0，320×240，DPR 由对应 profile 固定。每项五轮交替运行基线/候选，使用独立页面或真实 Worker、固定随机数和逻辑时钟。每轮 90 个连续交互帧，丢弃前 30 帧后统计稳定帧；另采七次回收后首帧和 140 个恢复后的稳定帧。GPU 首帧测量在回收后同步重建，Canvas 首帧测量在 clear 释放派生工作缓存后重建。

CPU 帧计时覆盖 `_renderFrame`，输入派发在计时外；初始化包含后端就绪等待。GPU 完成等待不计入 CPU 帧耗时，不代表显示器帧率。原生计时分辨率约 0.1 ms，初始化每版本每配置仅五个样本。性能采样没有加入默认发布门禁。
